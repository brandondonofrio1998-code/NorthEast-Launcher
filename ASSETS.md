# Assets

Every visual asset in this app is original work made for this project. No third-party images,
fonts, icon packs or stock art are bundled.

| Asset | File | Source | License |
|---|---|---|---|
| Pine-ridge backdrop (3 layers) | `app/src/main/res/drawable/pine_ridge_{far,mid,near}.xml` | Original. Generated by `tools/gen_pine_ridge.py` (deterministic, fixed seed); tinted per season at runtime. | Same as this project |
| TV banner | `app/src/main/res/drawable/banner.xml` | Original vector, hand-written. | Same as this project |
| App icon | `app/src/main/res/drawable/ic_launcher.xml` | Original vector, hand-written. | Same as this project |
| Woodland color palette, seasonal accents & tree colors | `app/src/main/java/com/northeast/launcher/ui/theme/Theme.kt` | Original color choices. | Same as this project |

**Fonts:** the system default font of the TV (no bundled font files).

**App icons shown on tiles** belong to their respective apps; they are read from the device at
runtime through Android's PackageManager and are never copied into this repository.

If a CC0 asset is ever added, list it here with its source URL and license.
